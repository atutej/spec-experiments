# Aurora online DSpark drafter, target Dr. Doom, R2E-Gym train prompts, warm start from targetgen warm80k

Inspired by the reference setup's R2E-Gym adaptation of its EAGLE-3 draft (`laion/snowball-64k-eagle3-draft-r2egym`), here with our DSpark warm80k drafter and Aurora's online loop. **Not run yet** (2026-11-01): prompts built, scripts written, smoke not submitted.

- **Target:** `open-athena/Grug-67B-A2B-Datakit-SFT-262K-2026.09.21-dr-doom` (the user's choice; the reference setup's target is the Snowball S3 Nemotron-Terminal step-1888 checkpoint, `laion/snowball-67b-a2b-sft-s3-nemotron-terminal-step1888`).
- **Drafter start:** `runs/eval_ckpts/drdoom_targetgen_warm80k_final`. Everything else is the RLVR runs' recipe (`../aurora_grug-67b-a2b-dr-doom_rlvr-train_dspark-online`, see its NOTES.md): lr 1e-5, 30 warmup steps, 32 samples per optimizer step, Aurora forward KL with 0.8**i position weights, frozen confidence head, draft sync every 8 steps, completions up to 4,096 new tokens, trainer / Mooncake sequence length 8,320.
- **Prompts (single-turn, the user's choice):** `runs/r2egym_train_prompts_20261101/prompts_token_ids.jsonl` from `make_prompts.py`: every R2E-Gym task in the tasks dir (8,101) except the 1,024 tasks of the eval prompt set (`runs/r2egym_prompts_1024`), the task's `instruction.md` as one user turn through the target's chat template (same rendering as the eval prompts, `/think` header), prompts up to 4,096 tokens. `manifest.json` next to it lists the tasks. The real agent (terminus-2) wraps the instruction in its own system prompt and runs many turns, so these are a first-turn proxy and the target's replies (about 700 tokens on average) are far shorter than agent trajectories.
- **Difference from the reference setup:** its model card says the draft was adapted on 2,177 prefixes (about 64M input tokens, 32M supervised, prefixes up to 32k tokens) from target-generated R2E-Gym "probe trajectories". Its repo README says its generation tool makes "one continuation per supplied prompt" and "does not execute tools or build a complete agent rollout" but does not say how the probe trajectories were produced, so whether his data came from executed agent rollouts is NOT confirmed. This run trains on the target's replies to single-turn instructions only.

Run (from a LOGIN node; the slurm output dir `runs/aurora_drdoom_r2egym_warm80k_20261101/` exists): smoke first, `sbatch run_smoke.sbatch` (4 optimizer steps, 128 rollouts, 1.5 h, no W&B), then `sbatch run_long.sbatch` (4 h; W&B `marin_aurora`, group `dspark-drdoom-r2egym-warm80k-<jobid>`). Drafts land in `runs/aurora_drdoom_r2egym_warm80k_20261101/long_<jobid>/drafts/step_N`.

Evaluate a draft like the Figure 1 / 3 cells of the blog draft: Dr. Doom, T=1, concurrency 16, N=8, probabilistic drafting, R2E-Gym 1,024 first-turn eval prompts (`runs/r2egym_prompts_1024`, 4,096 new tokens), with a same-session pristine warm80k arm (reference numbers: warm80k R2E-Gym AL 2.657 at concurrency 512, from the grid). Also report RLVR, Datakit held-out and big-mix held-out to see whether the adaptation costs anything elsewhere (the Step12 Datakit-online run lowered AL on other sets, see the Step12 RLVR folder's NOTES).
