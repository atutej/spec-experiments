## Training data

Rows of the Datakit SFT mixture (the data the target was fine-tuned on: 203 sources, 6,471,159 rows, 45.99B tokens after clipping rows at 32,768 tokens), **selected by similarity of their first turn to the Snowball RL prompts**, with no deduplication.

- **RL prompts (queries):** all 84,403 train rows of [`open-athena/Nemotron-RL-Ultra-RLVR1-Cleaned-v3-2026-09-30`](https://huggingface.co/datasets/open-athena/Nemotron-RL-Ultra-RLVR1-Cleaned-v3-2026-09-30), the system message (if any) plus the first user message.
- **Embedding:** `google/embeddinggemma-2` (revision `914f7f89142e33e77833254d9c9b90c3cef7303b`), bf16, task prefix `task: sentence similarity | query: ` on both sides, text `system + "\n\n" + first user turn`, left-truncated to 8,192 tokens. For a Datakit row the first system header (reasoning mode and tools block) is skipped; tool definitions are not embedded on either side.
- **Selection:** the exact cosine top-64 of every RL prompt over all 6,471,159 rows (brute force). Round r takes every RL prompt's r-th nearest row, until a budget of 9.7B packed tokens: 16 complete rounds plus a partial 17th, whose prompts are a seeded random subset (seed 0). No similarity cutoff.
- **No deduplication:** 1,379,901 rows were selected but only **411,172 are distinct** (968,729 repeats, 70.2%); the distinct rows hold 2.50B tokens of the 9.70B. A distinct row is selected 3.4 times on average (median 2, 99th percentile 23, at most 3,826). Mean cosine similarity of the nearest row is 0.942, falling to 0.900 at rank 17.
- **Dataset:** the 1,379,901 selected rows, shuffled (seed 0): 9.70B tokens, 7.79B supervised assistant tokens, 215 shards. The last 0.1% of rows is held out for validation, so repeated rows can fall in both training and validation.

[`training_data_selection.json`](training_data_selection.json) has the parameters and the counts above. [`training_data_selection_rows.npz`](training_data_selection_rows.npz) lists the selection in order: `global_row` (the row's index in the Datakit dataset, shards in file order), `rank`, `rl_index` (row of the RL train split) and `score` (cosine), `seq_len`. The Datakit mixture is the one of the [target card](https://huggingface.co/open-athena/Grug-67B-A2B-Datakit-SFT-262K-2026.09.21/blob/main/training_data_mix.json) (Marin's [`special_token_1000_mix.json`](https://github.com/marin-community/marin/blob/82620ad62bbe23b9b12a89d656c24e6f80aff91a/experiments/grug_sft/special_token_1000_mix.json)).
